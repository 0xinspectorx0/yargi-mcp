📱 Mobil Kullanım & Kurulum Rehberi
📲 1. Telefona Uygulama Olarak Ekleme (PWA)
iOS (iPhone / iPad) Safari:
1. Safari'nin altındaki Paylaş simgesine (kare içinde yukarı ok) dokunun.
2. Aşağı kaydırıp "Ana Ekrana Ekle" seçeneğini seçin.
3. Sağ üstteki "Ekle" butonuna basın. Uygulama telefonunuzun ana ekranında yerel bir app gibi çalışacaktır!

Android (Google Chrome):
1. Chrome'un sağ üst köşesindeki üç nokta menüsüne dokunun.
2. "Ana Ekrana Ekle" veya "Uygulamayı Yükle" butonuna basın.
🤖 2. Claude Mobil Uygulamasında Kullanma
Yargı MCP'nin Remote MCP sunucusu sayesinde bilgisayar kurulumu yapmadan doğrudan LLM istemcilerine bağlanabilirsiniz:

🔗 Remote MCP URL:
https://yargimcp.fastmcp.app/mcp
Claude Desktop / Web:
Claude masaüstü veya web üzerinden Settings → Connectors → Add Custom Connector adımından yukarıdaki URL'yi eklediğinizde, telefonunuzdaki Claude uygulamasında aynı sohbet oturumu üzerinden Yargı MCP araçları kullanılabilir hale gelir.
💬 3. ChatGPT Mobil ile Kullanma (Custom GPT)
ChatGPT Plus/Team/Pro kullanıcıları, Yargı MCP'nin REST API şemasını bir Özel GPT (Custom GPT) Action olarak ekleyebilir. Böylece ChatGPT iOS/Android mobil uygulamasında "Yargıtay kararlarını ara" diyerek doğrudan kararları sorgulayabilirsiniz.
